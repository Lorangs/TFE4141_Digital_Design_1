RSA Encryption:
    C = M^e mod n, M < n            public key {e, n}

RSA Decryption:
    M = C^d mod n        


M = (M^e)^d mod n       Restric the values of e, d, n           

M = Message
C = Encrypted Message
n = Part of keys
e = Rest of encryption key
d = Rest of decryption key


Generating the keys:
Theta(n): Eulers Totient function

    1)
        Select two prime numbers: p and q
    2)
        compute n = p*q
    3)
        compute Theta(n) = Theta(p) * Theta(q) = (p-1)*(q-1)
    4)
        Select e such that gcd( Theta(n), e) = 1, 1 < e < Theta(n)   
        gcd = Greatest Common Divider     
    5)
        compute d = e^(-1) mod Theta(n)



Algorithm for M^e mod n
    (Repeated Squaring)

    e = 0d55 = 0b00110111       binary
    e = 1*2⁵ + 1*2⁴ + 1*2² + 1*2¹ + 1*2⁰

    M^55 can the be written as:
    M = M^(2⁵ + 2⁴ + 2² + 2¹ + 2⁰)
    M = M^(32 + 16 + 4 + 2 + 1)
    M = M^32 * M^16 * M^4 * M^2 * M^1


    c = M           e0 = 1
    P = M*M         

    c = P*c         e1 = 1
    P = P*P         M⁴
    c = PÆc         M⁴ * M² * M¹


    psudocode for Algorithm (complexity O( log e ))

    c = 1
    P = M
    for i=0 to k-1:
        if e[i] = 1:
            c := c*P 
        P = P*P 
    return c


Hardware requirments:
    - Multiplication of large numbers (c*P) and (P*P)

    A = 0b1001  (9)
    B = 0b1011  (11)
    r = A*B = 1100011         (99)

    multiplication algorithm:
    r = 0   
    for i =0 to k-1                 // start calculation with MSB
        r = 2*r + A*B[k-1-i]        //bitshift r one step 
    return r

    Example:
    i = 0, k-1-i = 3
    r = 0 + 0b1001 * 1 = 0b1001

    i = 1, k-1-i = 2
    r = 0b1001 * 2 + 0b1001 * 0 = 0b10010

    i = 2, k-1-i = 1
    r = 0b10010 * 2 + 0b1001 * 1 = 0b101101

    i = 3, k-1-i = 0
    r = 0b101101 * 2 + 0b1001 * 1 = 0b1100011


Modular exponentiation:
    Replace all multiplications by modular multiplication
    
    (6*8*3) mod 5
    6 = 1 mod 5
    1 * 8 = 3 mod 5
    3 * 3 = 9 = 4 mod 5


example with Modular exponentiation within multiplication algorithm
    r = 0

        r = 2*r + A*B[k-1-i]

    return r


Some notions to remember:
    (r mod N) <= N-1
    A*B <= N-1

    0 <= r <= 2*(N-1) + (N-1) = 3(N-1)
